For Gmail (easiest):
  EMAIL_PROVIDER=gmail
  GMAIL_USER=your.email@gmail.com
  GMAIL_APP_PASSWORD=xxxx_xxxx_xxxx_xxxx

To get Gmail App Password:
  1. Go to: https://myaccount.google.com/security
  2. Enable "2-Step Verification"
  3. Search "App Passwords" → Create → Mail → Generate
  4. Copy the 16-character password

⚠️ Troubleshooting
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem: "npm not recognized"
Solution: Restart your computer after installing Node.js

Problem: Port 5000 already in use
Solution: Edit backend\.env → Change PORT=5001
         Edit frontend\.env → Change VITE_API_URL=http://localhost:5001/api

Problem: Sharp install fails
Solution: In backend folder run:
         npm install --ignore-scripts
         npm install sharp

Problem: Email not sending
Solution: Verify your GMAIL_APP_PASSWORD is correct (16 chars)
